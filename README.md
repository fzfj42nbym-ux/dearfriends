# Dear Friends

Исходники сайта **Dear Friends** — сообщества друзей с рисованными персонажами, анимационной сценой на диване, событиями, галереей и чатом.

## Сайт и домен

- Сайт: https://dearfriends.ru (начнёт открываться после настройки GitHub Pages и DNS).
- GitHub: https://github.com/fzfj42nbym-ux/dearfriends
- Главная страница: `index.html`.
- Сборка не требуется: обычные HTML, CSS и JavaScript.

## Публикация

1. Откройте **Settings → Pages** этого репозитория.
2. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
3. В **Custom domain** укажите `dearfriends.ru` и сохраните, если не подставился автоматически из `CNAME`.
4. У регистратора домена настройте для корня (`@`) четыре A-записи GitHub Pages:

   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`

   Для `www` по желанию CNAME → `fzfj42nbym-ux.github.io`.

5. После выпуска сертификата включите **Enforce HTTPS** в настройках Pages.

Не удаляйте DNS-записи, относящиеся к почте (MX, SPF, DKIM), если почта на домене используется.

## Текущие ограничения

Интерфейс и иллюстрации перенесены. Чат, события и фотографии в исходном проекте подключались через неуниверсальные API Claude:

- `claude.use('db')`
- `claude.use('assets')`

На GitHub Pages этих сервисов нет: общие данные между пользователями не синхронизируются, а загрузка фотографий недоступна. Для восстановления совместной работы потребуется отдельный backend/storage и авторизация.

**Приватность:** репозиторий и GitHub Pages публичны. Не публикуйте здесь личную переписку, приватные фото, токены или другие чувствительные данные; ограничение доступа к сайту нужно реализовывать отдельно.

## Изменения другими нейросетями

Откройте этот репозиторий в ChatGPT/Codex, Claude Code, Gemini или другом редакторе, подключенном к GitHub. Для правил работы над проектом читайте [AGENTS.md](AGENTS.md).

Изменения удобнее делать в отдельной ветке с Pull Request. После слияния в `main` GitHub Pages автоматически публикует изменения.
