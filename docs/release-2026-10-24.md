## Рабочая база

Публикация GitHub Pages обновляет статические файлы и не применяет SQL.
Для общей библиотеки, атомарного создания переписок и актуальных ограничений
фонда/чеков/челленджей нужно выполнить весь `supabase/schema.sql`
в SQL Editor проекта Supabase. Повторный запуск и сохранность существующих
данных проверены в изолированном PostgreSQL. Рабочая база из этой среды
не изменялась: административного доступа к ней нет.
Демо и оформление работают без применения SQL.
