# Общие иконки Dear Friends

Единственный исходник рисунков — SVG с классом `icon-defs` в [`index.html`](../index.html).
У каждого `<symbol>` есть стабильный ключ `dfi-*`, русское имя `data-label` и группа
`data-category`: `section`, `media`, `action` или `state`. Цвет наследуется от
интерфейса (`currentColor`); стандартная сетка — 24 × 24, обводка — 1,8 с круглыми
окончаниями и соединениями. У контейнера можно явно задать `data-stroke-width`.

На сайте иконки вызываются через `uiIcon('chat')` или локальный SVG `<use>`.
Рисунки персонажей, стикеры и эмодзи сообщений к этому набору не относятся.

## Обновление набора

1. Изменить или добавить `<symbol>` в исходном HTML. Существующие ключи сохранять,
   чтобы при переносе приложения не пришлось переписывать все обращения.
2. Запустить экспорт из корня проекта:

   ```bash
   python3 -B scripts/export_icons.py
   python3 -B scripts/export_icons.py --zip /tmp/dearfriends-icons-kit.zip
   ```

3. Открыть [`assets/icons/preview.html`](../assets/icons/preview.html). Это автономный
   каталог с поиском по имени/ключу и фильтрами групп; работает без сети и шрифтов CDN.
   Вместе проверить изменённую иконку на сайте: в светлой и тёмной теме, рядом с подписью
   и в маленькой кнопке.

`--output-dir /tmp/my-icon-kit` создаёт отдельную копию. Экспортёр отказывается
записывать набор в корень проекта и в непустой каталог без собственного manifest.
Посторонние файлы не удаляются; для списка актуальных иконок используется manifest.
Повторный экспорт того же исходника даёт те же файлы и те же байты ZIP.

## Что входит в экспорт

- `*.svg` — отдельный SVG для каждого ключа с собственными параметрами обводки.
  Файлы не зависят от CSS основной страницы, `<use>` и внешней сети.
- `sprite.svg` — общий SVG-спрайт с теми же ключами `dfi-*`.
- `manifest.json` — версия формата, общие параметры, ключи, русские имена, группы,
  `symbol_id`, имена файлов и `viewBox`. `label_ru` — подпись в каталоге, а не
  обязательное имя кнопки: доступное имя задаётся по действию в конкретном интерфейсе.
- `preview.html` — встроенные SVG и локальный поиск. Все перечисленные файлы также
  попадают в ZIP, если указан `--zip`.

Перед записью проверяются уникальность ключей, метаданные, геометрия, `viewBox` и
статические `href="#dfi-*"` исходной страницы. Динамические обращения дополнительно
проверяются в браузере вместе с интерфейсом.

## Использование на сайте и в приложении

Для HTML/WebView можно перенести спрайт вместе с `manifest.json` либо вставить
геометрию отдельного SVG в компонент. Размер и цвет задаются компонентом:

```html
<button type="button">
  <svg width="20" height="20" viewBox="0 0 24 24"
       aria-hidden="true" focusable="false">
    <use href="assets/icons/sprite.svg#dfi-chat"></use>
  </svg>
  Чат
</button>
```

Для внешнего спрайта предпочтителен локальный HTTP-сервер приложения. Для одного
самодостаточного HTML спрайт встраивается в документ, как в `index.html`.
При использовании через `<img>` задавайте `alt` и учитывайте, что `currentColor`
внешнего SVG не наследует CSS-цвет родительской HTML-кнопки: для смены темы удобнее
inline SVG или компонент.

В React Native файлы можно импортировать через стандартную SVG-библиотеку и её
трансформер или преобразовать геометрию в `react-native-svg`. В Flutter — подключить
как assets через SVG-компонент. Ключи manifest подходят для общего сопоставления
экранов и действий с иконками; размеры, цвет и доступность остаются ответственностью
компонента соответствующей платформы. Готового нативного приложения этот экспорт
не создаёт и зависимости в основной сайт не добавляет.

Иконка рядом с текстом декоративная (`aria-hidden="true"`); кнопке только с иконкой
нужно понятное имя (`aria-label` в HTML или соответствующее свойство платформы).
Для касания сохраняйте область кнопки не менее 44 × 44, даже если сам рисунок 20 × 20.
