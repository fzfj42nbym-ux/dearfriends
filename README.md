# Dear Friends

Исходники сайта **Dear Friends** — сообщества друзей с рисованными персонажами, анимационной сценой на диване, событиями, галереей и чатом.

## Сайт и домен

- Сайт: https://dearfriends.ru (начнёт открываться после настройки GitHub Pages и DNS).
- GitHub: https://github.com/fzfj42nbym-ux/dearfriends
- Главная страница: `index.html`.
- Сборка не требуется: обычные HTML, CSS и JavaScript.

## Публикация

1. Откройте **Settings → Pages** этого репозитория.
2. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
3. В **Custom domain** укажите `dearfriends.ru` и сохраните, если не подставился автоматически из `CNAME`.
4. У регистратора домена настройте для корня (`@`) четыре A-записи GitHub Pages:

   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`

   Для `www` по желанию CNAME → `fzfj42nbym-ux.github.io`.

5. После выпуска сертификата включите **Enforce HTTPS** в настройках Pages.

Не удаляйте DNS-записи, относящиеся к почте (MX, SPF, DKIM), если почта на домене используется.

## Сверка с версией в ChatGPT

В репозиторий загружен исходный HTML-снимок `friends-club.html` (в нём подпись `v0.1`). В опубликованном ChatGPT Site встречается версия `v0.2` с персонажем «Коля “Усики”». Её редактируемый исходный код пока не был доступен для экспорта. Поэтому внешний сайт может отличаться от самой новой внутренней версии. Для полного переноса требуется получить и сравнить исходник `v0.2`; не выдумывать детали иллюстраций.

## Приватный клуб: Supabase (вход, чат, фото, помощь)

Сайт подключается к Supabase — бесплатному сервису, который даёт авторизацию,
общую базу, хранилище фото и живой чат. Настройка по шагам:

1. **Проект создан**: `https://dlvjdnligiizwnpibwin.supabase.co`.
2. **Создать таблицы**: в Supabase откройте **SQL Editor → New query**,
   вставьте целиком файл [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**.
   Повторный запуск безопасен.
3. **Пригласить друзей**: в конце `schema.sql` замените строку-пример и выполните:
   ```sql
   insert into public.members (email, name) values ('drug@pocta.ru', 'Настоящее имя');
   ```
   Человек сможет войти только с почты из этого списка (вход по ссылке из письма,
   без пароля). Имя из `members` показывается в чате.
4. **Вставить ключ**: в Supabase **Settings → API** скопируйте `anon public` key
   и вставьте его в `index.html` вместо `PASTE_ANON_KEY_HERE` (константа `SB_KEY`).
   Это публичный ключ — его можно коммитить. **`service_role` key никогда не
   коммитьте и никому не пересылайте.**
5. **Ссылки для входа**: в Supabase **Authentication → URL Configuration** добавьте
   в **Redirect URLs**: `https://dearfriends.ru` и `https://dlvjdnligiizwnpibwin.supabase.co/auth/v1/callback` (для локальной проверки — `http://localhost:8000` и т.п.).
6. **Письма со ссылкой**: встроенная почта Supabase шлёт ~2 письма в час — для
   теста хватает. Для клуба настройте свой SMTP в **Authentication → SMTP**.

Пока `SB_KEY` не вставлен, сайт работает в демо-режиме: интерфейс доступен,
но данные не синхронизируются, фото не загружаются.

### Мессенджер

Раздел «Чат» — полноценный мессенджер клуба:

- **Все друзья** — общий чат (старая таблица `chat`).
- **Личные диалоги** — кнопка «＋ диалог», выбираешь друга из списка.
- **Группы** — «＋ группа», название и любой состав участников.
- **Изюминка**: у сообщений вместо ников — рисованные персонажи сайта, плюс
  эмодзи-реакции (наведи на сообщение). Реакции и переписки видны только
  участникам конкретного чата (RLS).
- Чтобы у друга в чате был персонаж, назначь его в Supabase:
  ```sql
  update public.members set char = 'kazar' where email = 'drug@pocta.ru';
  ```
  Доступные ключи персонажей: `kazar, alice, misha, diana, artemiy, marina,
  khariton, natasha, yulia, nikita, lena, kira, dima, sasha, vitya, vova, jenya`.

### Как защищены данные

- Всё закрыто правилами RLS на стороне сервера: читать и писать могут только
  вошедшие пользователи из белого списка `members`.
- Фото лежат в приватном бакете `photos`; в галерее выдаются временные
  подписанные ссылки (на час).
- Паролей нет — вход по одноразовой ссылке на почту.

Репозиторий и сам сайт остаются публичными (это нормально: код не содержит секретов),
но все данные участников — события, чат, фото, просьбы — видны только членам клуба.
