# Перенос разделов из GitHub

Статус на 24 октября 2026 года: перенос завершён, браузерные и серверные
проверки и финальная визуальная сверка прошли.
Рабочая ветка — `feature/sync-club-features`, основана на актуальном `main`
(`61e3ba3`) с сохранением локальных изменений интерфейса. Коммит переноса,
публикация сайта, отправка ветки и применение SQL к рабочему Supabase в рамках
этой работы не выполнялись.

## Исходная версия

При свежей сверке `main` на GitHub указывает на `61e3ba3`. В нём уже есть четыре
раздела, отсутствовавших в старой основе локального предпросмотра (`23516cc`):

| Коммит | Раздел | Возможности из GitHub |
| --- | --- | --- |
| `b6d64e7` | Дни рождения | Собственная дата, ближайшие праздники, поздравление сегодня |
| `0e3f78e` | Челленджи | Создание, дедлайн, участие, удаление своего вызова |
| `d2f4272` | Чеки | Сумма и фото покупки, история, распределение расходов |
| `61e3ba3` | Фонд | Взносы с комментарием, общая сумма, число взносов и участников, история |

Переносится содержимое этих функций в текущий `index.html`, а не старая длинная
главная целиком. Сцена комнаты, исходные 17 SVG-героев и диван, библиотека,
иконки, навигация окнами и изоляция демо сохранены. База рабочей ветки
обновлена до GitHub `main`, функции встроены в новый интерфейс; удалённый
`main` не изменён.

## Окна и демо

В меню «Ещё» четыре карточки ведут в действующие разделы: `#fund`, `#receipts`,
`#challenges` и `#birthdays`. Старые ссылки из GitHub `#rc`, `#chal` и `#bday`
сопоставляются новым окнам. Виш-листы, мастерская стикеров и комната с общением
за столом остаются окнами с планами.

Вход `123` предназначен для интерфейсной проверки: данные вымышлены и живут
только в памяти вкладки до перезагрузки. Доступны локальные
взносы и удаление своих записей, чеки и расчёт долей, создание челленджа и
участие, сохранение пробной даты рождения. При переходе из настоящего клуба
в демо запоздалые ответы Supabase не возвращают приватные сведения.

Фонд учитывает взносы; банковских переводов и формы расходования кассы нет.
Чеки распределяют общую сумму между участниками; автоматического списания
из фонда нет. Поздравительный баннер не отправляет сообщения друзьям.

## Данные и обновление схемы

Сохраняются имена таблиц GitHub: `fund`, `receipts`, `challenges`,
`challenge_join` и поле `members.birthday`. Чеки используют существующий
приватный бакет `photos` и временные подписанные ссылки на изображения.

Обновление [`supabase/schema.sql`](../supabase/schema.sql) должно быть повторяемым
и сохранять существующие записи и защиту библиотеки с мессенджером. Правила
новых разделов проверяются на сервере: доступ только участникам, действия
со своей записью и датой рождения — от имени вошедшего пользователя.
Клиентские проверки не заменяют RLS.

Существующие отрицательные движения в `fund` сохраняются при повторном запуске;
новые взносы через клиент должны быть положительными конечными суммами.
Обновление своей строки `members` ограничивается полем `birthday`.

Перед публикацией общей версии потребуется выполнить актуальный `schema.sql`
в SQL Editor нужного Supabase-проекта. Здесь рабочая схема не изменялась;
наличие кода в GitHub само по себе не подтверждает применение схемы к серверу.

## Проверки

Для повторной проверки из корня репозитория:

```bash
python3 -B -m unittest discover -s tests -p 'test_*.py' -v
python3 -B tests/check_club_features_sql.py
python3 -B scripts/export_demo.py /tmp/dearfriends-club-demo.html
```

Браузерные проверки используют локальные Playwright/Chromium, тестовый backend
и заблокированные внешние запросы. Серверной проверке нужен локальный Docker:
она создаёт изолированный PostgreSQL 16 без сети и опубликованных портов,
использует тестовые данные и удаляет контейнер. Рабочий Supabase не используется.
Экспорт сохраняет
встроенные изображения комнаты и не требует соседних файлов в `srcdoc`.
Подтверждены 74 браузерные проверки: 11 новых возможностей, 10 навигации
и 53 регрессии мессенджера, библиотеки и сырого предпросмотра. Также прошли
57 серверных утверждений на изолированном PostgreSQL 16.15. В том числе
проверены ошибки и повторная отправка, черновики, отсутствие двойной записи,
фото и расчёты в копейках, переход из клуба в демо, повторный запуск SQL,
обновление прежних политик, сохранение старых данных, приватность бакета
и права на свою дату рождения.

В локальном Chromium вручную просмотрены 19 кадров: все четыре окна на
375 и 1440 px, меню «Ещё», главная и дополнительные мобильные формы и списки.
Проверены взнос 250,50 ₽ с обновлением суммы фонда до 1750,50 ₽ и чек 123,45 ₽
с пробной фотографией и открытием изображения. Критических или мешающих
использованию дефектов не найдено; ошибок JavaScript, внешних запросов
и внешней прокрутки страницы не обнаружено.

Примеры фактических кадров:

- `/workspace/shared/club-sync-1440-fund.png` — фонд на большом экране.
- `/workspace/shared/club-sync-375-fund-added.png` — мобильный фонд после взноса.
- `/workspace/shared/club-sync-375-more.png` — четыре действующих раздела в «Ещё».
- `/workspace/shared/club-sync-375-receipts-photo.png` — фото чека.

Метрики сохранены в `/workspace/shared/club-sync-qa-metrics.json`, автономное
демо — `/workspace/shared/dearfriends-club-updated.html`. Это локальные
артефакты проверки, не общедоступный адрес опубликованного сайта. Физический
телефон и облачная страница пользователя напрямую не проверялись.
Рабочие GitHub `main` и Supabase не изменялись.
